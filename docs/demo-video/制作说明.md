# LabDeck 作品演示视频素材包

这是参考图、镜头提示词与剪辑方案，不是已经生成的动画成片。按 16:9 横屏、1920×1080、30fps、总长约 6 分钟规划。五段动画共 53 秒，实机段共 307 秒。六分钟为制作建议。

## 先打开什么

1. 打开「分镜预览.html」，查看五段参考图、节拍和可复制提示词。
2. references/ 有两张 AI 场景原图、四张 1920×1080 信息画面 PNG。后者由 editable/ 中的 SVG 渲染。
3. prompts/ 每段一个 Markdown：含可粘贴提示词、目标时长、旁白、字幕和衔接方式。
4. 「时间线与录屏清单.csv」可用 Excel 打开，按编号准备录屏和剪辑。
5. 「动画段旁白定位.srt」仅作五段动画旁白的时间定位，需按最终配音语速拆成短字幕；实机段旁白另录。

## 风格与制作分工

颜色：炭灰 #191b1d、石板灰 #282b2e、灰蓝 #a9c5df、少量青绿 #176b63、暖光 #dec087。中文建议使用系统已有的微软雅黑或思源黑体；标题大、信息少、字号清晰，四周保留至少 96px 安全边距。

A01、A05：使用内置 imagegen 生成的匹配场景原图。上传到你选用的视频工具，按各段提示词制作慢推/慢拉镜头。场景图保留原始尺寸，不伪称为 1080p 原生画面；在 16:9 工程中适配，先检查清晰度。

A02、A03、A04：使用代码生成的可编辑 SVG 与 PNG 参考帧。推荐在剪辑软件中用逐层显现、描线和两帧状态切换制作；图生提示词也已提供，用于生成无字背景。中文、命令、参数与预算由后期准确叠加。

所有场景画面和参数框图为说明性视觉，不能替代实机验证。参考参数 0.001/0.01 与 seed 42/2026 只是算术示例；录屏时使用项目真正支持的参数，保持动画与录屏一致。模型给建议、仓颉做参数引擎、用户审查后才入队，这一责任划分在旁白与画面中保持一致。

## 实机与动画衔接

全片以 30fps 剪辑；8 帧约 0.27 秒、10 帧约 0.33 秒。以短溶解、同色背景和连续旁白连接。每段动画结束前留 1—2 秒稳定画面，每段录屏开始先停稳约 1 秒。训练等待允许剪辑压缩，切到结果时叠加“训练完成后 / 时间跳转”。

若图生工具提供首尾帧，可以按需要上传；本包仅 A04 提供语义明确的两个状态，其余为单张参考帧，不假定所有平台都支持同一生成模式。AI 人物不做口型、不做复杂手势，不让模型生成软件点击或指标。

## 五段镜头

- A01 分散的科研工作：00:00—00:10，10 秒。0—4 秒：看见研究者与分散的文件面板；4—8 秒：缓慢推进，后期依次出现“代码 / 环境 / 实验记录”；8—10 秒：定格并准备切入片头。
- A02 作品片头：00:10—00:16，6 秒。0—1 秒：灰蓝横线出现；1—2 秒：“LabDeck”淡入；2—4 秒：作品副标题淡入；4—6 秒：保持完整片头。
- A03 智能创建原理：00:45—00:57，12 秒。0—2 秒：“项目位置、实验目的”出现；2—6 秒：依次高亮读取文件、检查环境、询问缺口；6—9 秒：显示实验方案；9—12 秒：突出“人工审查后保存任务”。连线按 SVG 的既定方向绘制。
- A04 仓颉参数展开与预算：02:55—03:10，15 秒。0—3 秒：显示两个学习率和两个随机种子；3—6 秒：依次显现四份配置；6—9 秒：预算为 3，显示“阻止生成”；9—12 秒：切换预算为 4，显示“可进入人工审查”；12—15 秒：显示“确认本批后才加入任务队列”。
- A05 有依据的实验过程：05:50—06:00，10 秒。0—4 秒：回到与开场呼应的科研工作台，面板已有序关联；4—7 秒：后期出现“配置、运行与结果，有据可查”；7—10 秒：显示 LabDeck 与作品副标题，保持到片尾。

## 交付边界

已准备：六张参考 PNG、四个 SVG 源文件、五段完整镜头提示词、时长与衔接、旁白定位、六分钟录屏清单、离线预览页。AI 场景采用内置 imagegen；未调用付费视频生成服务，未生成连续视频或最终 MP4，未修改应用源码。
