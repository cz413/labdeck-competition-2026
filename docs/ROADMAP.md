# 后续功能优先级

当前已实现：任务与智能实验联动、确认修复后的进程跟踪、LangGraph 对照实验、结构化指标与产物元信息采集、结果口径区分、人工重新采集及隔离离线演示。

1. 实验复现档案：记录代码版本、工作区修改状态、依赖环境、GPU、seed 和用户声明的数据集版本，导出复现配置。
2. 多 seed 对照：按一致配置与指标口径分组，展示样本量、均值、波动和基线变化，缺少一致口径时明确限制。
3. 模型评测 Harness：建立脱敏故障案例集，比较规则与模型的诊断、证据引用、工具调用、耗时和成本。现有执行 Harness 和功能测试不能替代真实模型质量评测。
4. 跨批次研究记录：关联假设、配置、观察和下一批建议，记录建议依据与预算，后续执行仍需人工确认。

进程状态、证据完整度和研究结论继续分开。指标未达期望不触发运行故障诊断；checkpoint 存在不证明模型质量。

真实演示需在测试服务器记录一套实际训练及结构化结果采集，同时记录失败→诊断→确认修复→新运行的实际证据。离线预设数据和模拟 SSH / 模型联调不能代替真实训练效果证明。
