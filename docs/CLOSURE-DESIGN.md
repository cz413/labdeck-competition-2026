# 闭环界面设计

对象：科研人员在实验修复之后，确认新运行的实际结果。

沿用现有工作台 token：深色 surface #111921、text #e3e9ee、muted #63727c；浅色 surface #f8fafb、text #18232b；teal #277d76 / #58b8ae 表示动作与通过，amber #a66f18 表示证据待确认。标题与正文沿用 Segoe UI Variable / Microsoft YaHei UI，命令使用现有 Cascadia Code / Consolas。

复核：每项代表真实工作流阶段，不引入通用数据卡片与装饰编号。重点为当前阶段及验收证据，保留旧版主题与导航层次。进程通过与指标达标明确分开，暂停跟踪的按钮说明远程任务会继续。
