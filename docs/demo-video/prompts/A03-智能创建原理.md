# A03 · 智能创建原理

目标片长：12 秒。建议在六分钟成片的 00:45—00:57 使用。

参考图：../references/A03-smart-flow.png

## 使用方式

推荐用 SVG 分组制作节点显现动画；若图生视频，则只做小幅推镜，文字和连线后期重建。

## 可直接粘贴的图生视频提示词

16:9 横屏，克制的科研产品叙事。炭灰 #191b1d、石板灰 #282b2e、灰蓝 #a9c5df、少量青绿 #176b63 与暖光 #dec087；哑光材质，清晰轮廓，安静的大学科研环境。人物与桌面保持参考图的形象和布局。每段只采用一种运镜，保留字幕安全区。中文、Logo、命令、参数和指标统一后期叠加。

参考图片仅规定三列布局、炭灰灰蓝配色和信息层级，生成不含任何文字的科研流程动画底板。固定镜头，左侧两张输入卡片先以透明度显现，中间一块检查面板随后显现，右侧一张审查卡片最后显现。节点位置和外轮廓全程不变，不出现连线交叉。每张卡片内部保持空白，不生成文字、数字、代码或界面截图。最后 2 秒全画面稳定。

避免：霓虹赛博朋克、机器人、发光大脑、漂浮地球、快速环绕、强烈闪光、夸张表情、复杂手部动作、物体融化、桌面结构变形、额外人物、随机文字、乱码、水印、虚构性能数字。

## 剪辑节拍

0—2 秒：“项目位置、实验目的”出现；2—6 秒：依次高亮读取文件、检查环境、询问缺口；6—9 秒：显示实验方案；9—12 秒：突出“人工审查后保存任务”。连线按 SVG 的既定方向绘制。

## 旁白与后期文字

旁白：给出项目位置和实验目的，系统读取相关文件、检查环境，并生成可审查的方案；缺少的信息继续询问。

叠字：
项目与目的 → 文件与环境检查 → 可审查方案
人工审查后保存任务

## 衔接

入场：R01 实机录屏停稳后，8 帧溶解进入原理示意；角落保留“原理示意”标记。

出场：末尾突出右侧方案卡片；8 帧溶解到 R02 智能创建页面。进入录屏后先展示项目位置和实验目的，再开始分析。

配套录屏：R02：输入项目和实验目的 → 展示实际文件/行号依据 → 补充数据目录 → 修改并撤销一次 → 审查保存。

时长适配：以上为目标剪辑时长，不承诺平台能一次生成同样长度。平台只提供短片段时，采用两个简单镜头或剪辑延展，不叠加复杂动作。底图与生成画面不应被当作软件运行证据。
