# 比赛版功能记录

以下是独立比赛版的功能迭代记录。当前仓库从 0.5.0 源码快照开始记录 Git 提交；本文件不是此前 Git 历史的重建。

## 0.5.0

- 新增任务到对照实验的入口，支持手工或 AI 参数轴、配置差异、组合数及预算审查。
- LangGraph 编排确认、入队、等待、采集、诊断与分析，磁盘检查点支持重启恢复和部分入队去重。
- 实际编译仓颉 1.0.5 参数引擎，负责组合展开、去重、预算与命令生成，运行组件随程序打包。
- 自动提取日志指标，比较配置与证据；指标未提升不判故障，下一批建议仍需确认。
- 对照演示使用实际参数引擎、模拟运行与预设指标，不写入真实任务历史。

## 0.4.0

- 实验任务、指定运行与诊断报告准确联动；支持归档任务定位和报告返回原运行 / 修复运行。
- 基于已有任务生成新计划草稿，审查与排队继续由用户触发。
- 离线演示覆盖计划、OOM、确认修复、模拟成功 / 失败、重置和退出，演示会话只保存在窗口内存。

## 0.3.0

- 确认修复后自动跟踪新运行，结束时读取远程退出码；失败关联下一份诊断。
- 跟踪状态持久化；连接失败、退出码缺失或证据不足时有限退避重查，支持暂停、恢复和手动核验。
- 仅验收进程状态，后续修复仍需再次确认。

## 0.2.0

- 模型按日志选择受限只读工具，最多四轮请求和四项检查，每轮最多两项。
- 支持证据 ID 校验、重复检查去重、过程记录与停止诊断；模型失败保留规则结果和已有证据。

## 0.1.0

- 独立比赛版的智能实验入口：规则故障诊断、可配置模型分析、实验计划草稿与报告导出。
- 保留 LabDeck / LabDock 的既有服务器管理、GPU 资源与实验任务能力，并隔离比赛版数据。
