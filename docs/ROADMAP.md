# 后续功能优先级

当前实现：确认修复后的进程验收闭环、任务与智能实验双向联动、隔离离线演示（0.4.0）。

1. 指标验收与对比：从用户指定的 metrics.json / 日志字段读取 accuracy、loss、耗时，配置明确阈值或相对基线；缺指标时标记待确认。退出码通过但指标未达标时生成指标诊断。
2. 产物核验：检查用户明确指定的 checkpoint、结果文件与必要字段，记录文件大小 / 生成时间和运行归属；将产物存在与产物质量分别展示。
3. 更丰富的可审查修复方案：根据项目依赖声明和环境证据生成独立环境准备方案、路径参数调整。修改之前展示影响、执行前确认，保留原运行 / 原环境。
4. 实验经验库：保存失败类别、环境与代码版本、采用方案、验收结果。相似新失败只推荐条件相符的历史经验，不能把历史成功当作当前证据。

正式演示应先在测试服务器做一套可复现的失败任务，例如 batch size 过大触发 OOM，再由本项目完成诊断、确认减半、重新运行和退出码验收。记录实际日志、修改前后命令和结果，准确区分真实执行与模拟联调。
