# 任务联动与离线演示设计（0.4）

目标：在现有任务栏与智能实验之间传递准确的任务、运行和报告编号。导航只准备上下文，采集与修复由用户明确触发。报告返回任务时展开并定位指定运行，归档任务同样可定位。

沿用闭环设计中的工作台字体、深浅主题、teal 动作色和 amber 提示色。任务操作区增加诊断/计划入口，每次运行下展示对应诊断和修复验收；报告顶部提供原运行、修复运行入口。模型生成计划继续保存新草稿，不覆盖来源任务。

演示使用 App 内存中的独立会话，任务与服务器覆盖层只供这两个页面展示，不写入 AppStore、诊断历史或模型设置。服务器 mode=demo，模拟任务的真实编辑、队列、删除、终端等操作隐藏。诊断复用日志规则与 batch 修复生成器，运行、退出码、验收场景均明确标注模拟；模型开关对模拟任务不可用，模拟操作不会调用 SSH、模型或任务写入 IPC。

顶部演示控制条跨页面保留会话，可逐步推进：预设计划→模拟首轮 OOM→任务栏发起规则诊断→确认模拟修复→模拟开始→选择成功或再次失败。再次失败生成关联的新规则诊断，保留原运行。支持重置和退出，退出或重启仅丢弃内存演示数据，真实任务与诊断继续显示。

复核：采用已有任务详情/报告布局，避免另做假的任务面板。演示控制条左对齐，说明当前状态及下一步，模拟标记覆盖任务、报告、闭环和退出码。验证准确运行导航、失败链路和模拟过程零真实写入/采集；深浅主题截图检查溢出和可读性。

最终界面复核：深浅主题可读，1280×840 页面无横向溢出；演示控制条固定在滚动顶部，指定运行以 teal 边框高亮。报告、控制条、任务名称和退出码均明确注明模拟，临时节点不出现在真实计划的服务器列表中。
